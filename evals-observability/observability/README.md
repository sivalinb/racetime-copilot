# Observability: follow a run

Evaluation asks whether a result meets an expectation. Observability records what happened while producing it. Both are needed: a readable trace is not proof that an answer is correct.

## What is recorded

| Surface | Signals | Where to demonstrate |
|---|---|---|
| Evidence workflow | Step `name`, `status`, `durationMs`, `detail`; overall workflow time and cache hit | Streamlit → Evidence demo → Recap → Inspect this run’s trace |
| Evidence history | Saved traces, question and approval/rejection | History & traces |
| Video graph | Plan mode (`rule`, `llm`, `fallback`), action/reason, retrieval count, inspected interval, summary mode, human decision | Video workspace → Jobs / results → result JSON / Export result |
| Video jobs | Queued/running/failed/review/completed state, error, coverage gaps and limitations | Jobs / results |
| Usage | Rolling 24-hour provider calls and generation input/output token counts | Video workspace sidebar after sign-in |
| Human review | Durable checkpoint and resumed approve/reject decision | Jobs / results; persisted with SQLite/LangGraph |

Evidence trace durations of zero can mean a step is not individually timed. Video graph traces currently do not contain per-node durations. Token counts are not a full billing ledger: upload/embedding charges may be additional, and provider billing is authoritative. There is no deployed Prometheus/Grafana dashboard, distributed metrics service or alerting pipeline.

## Included trace examples

- [evidence-demo.json](examples/evidence-demo.json): regenerated by `npm run eval:benchmark`. Actual local runs over fictional observations show a conflict, a retrieval retry followed by recovery, and a cache hit for the repeated request. All four checks must pass.
- [video-integration-recorded.json](examples/video-integration-recorded.json): saved real Gemini trace on a synthetic red/blue clip. Follow `retrieve` (zero observations) → `inspect` → `retrieve` (two observations) → model-chosen `summarize` → `generated_verified`. The graph paused for review and resumed after restart with rejection because this was an integration check, not human factual approval.

The video snapshot is historical and has no cost/latency measurements. Do not describe it as a fresh provider run or real-race validation. `generated_verified` means the separate model grounding check accepted the answer; it does not guarantee truth.

## Live local demo

1. Start `python scripts/run_demo.py` after the normal setup. Open the Evidence demo.
2. Request Canyon Relay `00:00–15:00` and expand its trace. Show the two conflicting ridge reports and `verify` status.
3. Enable **Simulate one retrieval failure**, create the recap, and show `retrieve: retry` followed by `retrieve: ok`.
4. Repeat that identical request. Show `Cache: Hit` and the cache trace. Cache entries expire after five minutes; source revisions change the key.
5. Approve/reject and open History & traces. This evidence-demo review is a saved decision; the video workspace has the actual durable LangGraph interruption.
6. For an existing video result, open the exported JSON and explain `trace`, `gaps`, `limitations` and the selected evidence. Do not require a new provider call for the dependable demo.

## LangSmith

LangGraph run names and metadata are wired in the application. Configure `LANGSMITH_TRACING=true`, `LANGSMITH_API_KEY` and `LANGSMITH_PROJECT=racetime-copilot` in the ignored `.env`, then restart the app and worker. Never put a key in this folder or a screenshot.

The last external ingestion check returned **HTTP 429 because monthly trace quota was exhausted**. The local demo was subsequently started with external tracing disabled. Once quota is available, run a short authorized example and confirm that a new run reaches the project before presenting an external trace. Configuration alone is not proof of successful ingestion.

Local evidence traces and video job/checkpoint data remain available independently of LangSmith. Real requests may contain private source content; inspect and redact any exported trace before publishing it. The committed examples use fictional observations or the synthetic color clip.
